# Musika 🎵
**Next-Generation, High-Fidelity YouTube Music Client for Android**

Musika is a modern, high-performance Android music player built in 100% Kotlin and Jetpack Compose. Designed with an ultra-sleek glassmorphic dark theme, studio-grade audio processing, seamless YouTube library synchronization, and in-app automated updates.

---

## ⚡ Highlights

- 🎧 **Studio-Grade Audio Engine**:
  - Full 32-bit floating-point PCM audio pipeline with unclipped subtractive headroom.
  - Priority streaming in native 44.1 kHz AAC-LC (`audio/mp4`) for pristine highs and punchy, distortion-free low end.
  - Multi-band custom equalizer with hardware audio session binding and zero digital clipping.
- 🔁 **YouTube Library Synchronization**:
  - Direct, private account sync for Liked Songs, personalized Mixes, and custom playlists.
  - Dynamic reverse chronological ordering (newest favorites first).
  - Profile photo and personalized greeting support.
- 📻 **Endless Dynamic Radio**:
  - Intelligent queueing that dynamically discovers and queues similar music and new releases based on listening tastes.
- 💾 **Smart Offline Downloads**:
  - Multi-segment parallel background downloader with notification controls and storage quotas.
- 🚀 **In-App Auto-Updates**:
  - Automatically checks for updates on the first app launch of each day and presents an interactive glassmorphic update prompt with release notes.
  - One-tap background download with live progress and automatic installation.
  - Manual check anytime via **Settings → Updates & Version**.
